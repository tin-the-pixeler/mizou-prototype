# Modal

Mizou's single reusable modal anatomy — close icon, text-block, optional content slot, action-group.
Build every new modal from this component instead of forking a one-off from a Figma screenshot.

Anatomy source: Figma `Sales-trainer-MVP`, node `15431:254036`, section "Modals".

## The four hard rules

1. **Primary action is always rightmost.** Enforced by the component itself — the API takes `primary`/`secondary` as named props, `secondary` always renders before `primary` in the DOM, so you cannot flip the order through props.
2. **Never more than two buttons, or one button + one text-link — never both.** `actions` is typed so `textLink` and `primary`/`secondary` are mutually exclusive; combining them throws at construction time. There is no three-action pattern in the source design system — if a modal needs a third action, simplify the modal, don't extend the component.
3. **Width defaults to 600px.** `600` is a floor (`min-width`), not a fixed size. Only pass a larger `width` when content genuinely needs it (e.g. the 1489px two-column share-link layout) — state the content reason, don't reach for it by default.
4. **Close icon is hidden only via `dismissible={false}`.** Never hide it by deleting markup or with CSS. Non-dismissible is for modals the user must resolve with an explicit action (e.g. a blocking account migration) — it's an explicit, documented prop, not a missing icon.

## `content` vs a new modal type

Use the `content` slot for anything that fits inside the existing anatomy — a textarea, a loader, an image, two link
columns. If you're reaching for a third action or a layout the slot can't express, that's a signal to flag it for a
design review rather than extending the component ad hoc.
